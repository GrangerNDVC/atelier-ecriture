🔌 Test des clés API — Atelier d'Écriture

Ouvrez cette page depuis l'URL de votre app Netlify (ex : https://votre-site.netlify.app/test-api.html). Elle ne fonctionnera pas ouverte en local.

1️⃣ Test individuel des clés

Teste séparément chaque clé Mistral et OpenRouter configurée dans Netlify, sans passer par la logique de cascade.

2️⃣ Test de bout en bout

Appelle la vraie fonction utilisée par l'application (/.netlify/functions/gemini) et affiche quel fournisseur/modèle a réellement répondu.
Comment lire les résultats :
🟢 OK — la clé répond correctement.
🟠 Absente — la variable n'existe pas (ou pas ce nom exact) dans Netlify → Site configuration → Environment variables.
🔴 401 / Unauthorized — la clé est invalide, mal copiée (espace en trop, caractère manquant) ou révoquée.
🔴 429 — quota atteint pour cette clé.
🔴 402 — souci de compte/paiement côté fournisseur.
🔴 Failed to fetch — cette page n'est pas ouverte depuis Netlify.
